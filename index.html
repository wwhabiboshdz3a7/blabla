Ferme la main devant la caméra du téléphone pour « attraper » les photos, puis ouvre-la pour les envoyer au PC.

  1. Ouvre ce site sur le PC et choisis Mode PC.
  2. Sur le téléphone, scanne le QR code (ou tape le code).
  3. Choisis tes photos, active la caméra.
  4. ✊ Ferme la main devant le téléphone → photos attrapées.
  5. Pointe vers le PC et 🖐 ouvre la main → photos envoyées !
