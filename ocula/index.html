Moteur d'animation JavaScript · v2.4.0

Animez tout, de près comme de loin.

Ocula pilote CSS, SVG, attributs DOM et objets JavaScript avec une seule API. Timelines, ressorts, texte et scroll, le tout dans 9,8 ko.

Ce que l'oculaire révèle

Chaque image, nette. Chaque image, à l'heure.

Un seul moteur cadence vos animations sur l'horloge de l'écran, du premier pixel jusqu'à l'infini.

Fonctions

Six instruments, une seule API.

Chaque fonction s'importe seule. Les démos ci-dessous tournent en direct : touchez-les.

animate()

Toutes les propriétés

Transformations, couleurs, rayons, variables CSS et attributs SVG, interpolés au sous-pixel près.

stagger()

Décalages en grille

Une onde part du point touché et se propage selon la distance, en ligne, en grille ou au hasard.

Totalité · 2 min 41 s
createTimeline()

Séquences synchronisées

Enchaînez, chevauchez et bouclez des animations sur une seule ligne de temps, comme une éclipse.

spring()

Ressorts physiques

Masse, raideur, amortissement. Lâchez la lentille : elle revient au centre avec du rebond.

svg.createDrawable()

Tracés SVG

Dessinez n'importe quel chemin, puis faites suivre un objet le long de sa courbe. Ici, Cassiopée.

Sirius magnitude −1,46
scrambleText()

Texte brouillé

Chaque lettre défile au hasard avant de se poser. Les titres de la page, eux, sont découpés avec splitText().

Atelier

Une timeline, au centième de seconde.

Lecture, pause, retour arrière, vitesse et défilement manuel. Toute la séquence tient dans une seule timeline que vous pouvez scruter image par image.

0,00 s 
import { createTimeline, svg, stagger } from 'ocula';

const tl = createTimeline({ loop: true })
  .add('.planet', { scale: [0, 1], ease: 'outElastic(1, .6)' })
  .add(svg.createDrawable('.orbit'), {
    draw: ['0 0', '0 1'], delay: stagger(160)
  }, '-=400')
  .add('.m1', { ...svg.createMotionPath('#orbit-1'), loop: 3 }, 'lunes')
  .add('.m2', { ...svg.createMotionPath('#orbit-2'), loop: 1 }, 'lunes')
  .add('.m3', { ...svg.createMotionPath('#orbit-3') }, 'lunes');
